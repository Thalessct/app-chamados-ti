# Chamados TI

Projeto acadêmico em React Native + Expo + TypeScript.

## Escopo atual

- Painel de chamados
- Criação de chamado
- Detalhes do chamado
- Status: ABERTO e FECHADO
- Filtro por status
- Persistência local com AsyncStorage
- Navegação por Bottom Tabs
- Cards flutuantes e identidade visual cinza, azul e branco

## Como executar

```bash
npm install
npx expo start
```

Depois escolha Android, iOS ou Web no terminal/Expo.

## Estrutura

- `src/components` — componentes reutilizáveis
- `src/screens` — telas
- `src/theme` — identidade visual
- `src/types` — tipos TypeScript
